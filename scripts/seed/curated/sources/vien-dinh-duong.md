**Authority:** Viện Dinh Dưỡng Quốc Gia (NXB Y Học), latest edition.

This file is the citation index for ingredients whose macro values come from
the Vietnamese national food composition table ("VDDT"). Each entry below
documents the page + item code referenced from `scripts/seed/curated/vi-ingredients.ts`
via the `source_citation` field.

## Format
Each ingredient citation block looks like:

    ### <slug-id>  (matches `source_citation: 'sources/vien-dinh-duong.md#slug-id'`)
    - **VN name:** ...
    - **VDDT page:** ...
    - **VDDT item code:** ...
    - **Edition:** 2017
    - **Notes:** any normalisation done (e.g. "raw, edible portion only")
