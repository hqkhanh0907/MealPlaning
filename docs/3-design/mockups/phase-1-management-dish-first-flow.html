Design Spec Notes — Dish-first Management

  • Segment order: Món ăn | Thư viện nguyên liệu. `Món ăn` active by default.
  • Primary CTA: creating a dish, not creating an ingredient database record. Primary submit/save buttons use Coral CTA; Sage is reserved for brand, selected state, and supportive accents.
  • Ingredient quick-create: launched from dish ingredient search. CTA: Lưu và thêm vào món.
  • Ingredient library: supporting surface for correction/maintenance. Tap ingredient opens detail/read-only first; explicit Sửa thông tin opens edit.
  • Ingredient edit semantics: V1 edit is global. If an ingredient is used in dishes, show an impact warning before edit because dish totals derive from current ingredient data.
  • Data rules: dish totals remain derived from ingredient data through dish_with_totals; no manual total entry. Ingredient nutrition persists only as canonical 100g/100ml; khẩu phần/bao bì is input helper and must be converted before save.
  • User-facing copy: avoid factor_to_basis, normalized_amount, nutrition_basis_unit. Explain as “1 quả ≈ 60g”, “dữ liệu theo 100g/100ml”, “app sẽ tính như sau”.
