Token / RuleValueUsage
Single source of truthdish_with_totals / preview helper trước saveKhông có nhập tay total_*
RemovedQuick Add, manual total entryDish chỉ được lưu khi có ít nhất 1 dish_ingredient
Dish item modelamount_value + unit_id + normalized_amountMockup amount sheet phản ánh unit resolver thay vì enum cứng kiểu cũ
Unit displayHiển thị display label như quả, tbsp, ≈ nhúmKhông lộ field kỹ thuật unit_id ra user nếu không cần
Approximate unitBadge ước lượng + dấu ≈Vẫn tính vào total dish
Cross-dimension rulefactor_to_basis → density_g_per_ml → rejectCó screen riêng mô tả reject state
Bottom sheetPicker/search và amount entry đều dùng bottom sheet top radius 20pxKhớp design system BottomSheetPicker
Search patternSearch trong picker dùng field 44px, không nested sheetGiữ consistency của select pattern N ≥ 6
Total cardCalories + Protein + Carbs + Fat + Chất xơSync với canonical nutrients hiện có trong docs
ValidationName required, servings 0.5–20, cần ≥1 ingredientSave luôn active, invalid thì scroll tới lỗi đầu tiên
Delete/EditEdit mode có Lưu thay đổi + Xóa món ănKhông thay đổi dialog pattern chuẩn
Saving stateSpinner + disable interactionAsync submit only
