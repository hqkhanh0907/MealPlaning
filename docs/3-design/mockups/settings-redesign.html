Audit summary — đã sửa gì so với v2

  • Bỏ ring khỏi Settings Hub — ring biểu diễn progress (cần consumed_today_kcal) thuộc về Dashboard. Settings Hub chỉ trình bày target dạng list 2 row (Calo + Protein). Đúng audit logic: không hiển thị progress visualization khi Phase 1.5 chưa có data tracking.
  • Bỏ Carbs 360g + Fat 96g ở cả 3 màn (Hub, Body, Goals) — DB lưu target_carbs/target_fat = NULL sau onboarding, không có nguồn data.
  • Bỏ delta chip "▲ 300 vs hiện tại", "▲ 291 vs Nhẹ" — code không track previous selection, không thể tính delta.
  • Sửa goal #4: "Tuỳ chỉnh" → "Tăng hiệu suất" (đúng enum performance, +200 kcal, 2,0 g/kg).
  • Sửa Notification: 1 master toggle → 4 toggle riêng đúng schema notif_morning/lunch/evening/weekly.
  • Sửa Gender: 2 choice card → segment-control 2 button (DS §8g, match onboarding + body-edit).
  • Sửa Activity description đúng code: "Tập nhẹ 1–3 buổi/tuần" (không tự thêm "Đi bộ").
  • Sửa label button: "Lưu thay đổi" → "Lưu", "Khôi phục theo công thức" → "Reset về đề xuất".
  • Thêm row Phiên bản 1.0.0 ở Hub (đã có trong code).
  • Giữ + annotate NEW: Goal 2×2 card grid, Activity card có icon + TDEE-per-option, Theme segment 3-option (refactor từ IonRadioGroup) — visual upgrade cần thêm task implement riêng.

Onboarding ↔ Settings — gap đã phát hiện (chưa fix trong mockup)

  • Activity label lệch: Onboarding viết "Trung bình (3-5 ngày/tuần)", Settings viết "Vừa". Cần thống nhất 1 label const dùng chung.
  • Component pattern lệch: Onboarding step 2a dùng <app-form-field> (Signal Forms wrapper), Settings body-edit dùng raw .input-wrapper + .input-native. Cùng visual nhưng khác component → rủi ro consistency.
  • Activity factor hard-code 2 chỗ: Onboarding dùng ACTIVITY_FACTOR const, Settings activity-edit hard-code lại trong options array. DRY violation — nên import chung.
  • Settings thiếu sub-page sửa fitness_level: onboarding hỏi qua gymExperience nhưng Settings không cho sửa. Cần quyết định: thêm vào hay deferred Phase 2.
  • Mockup giàu hơn code: goalSummary() chỉ trả "Tăng cơ" — nên upgrade thành "Tăng cơ · 2 885 kcal · 165 g protein" để Hub thông tin hơn. activitySummary() tương tự.
