Design Spec Notes — Pantry / Measurement / Nutrition

RuleSpecImpact
Full-bleed / content insetMàn trong phone dùng `.content` padding 22px; nếu cần full-bleed dùng `.content.flush` rồi bọc `.inset` để không mất inset nội dung.Đã explicit để tránh layout tràn sát mép.
Pantry tách Ingredient`pantry_item` lưu quantity/location/expiry; `ingredient` lưu identity/nutrition/measurement.Không nhét hạn dùng/vị trí vào ingredient master.
Unit specificity`piece/cup/serving/package` phải có measurement riêng theo ingredient/product/state.Không dùng global `1 piece = x gram`.
Gross vs edibleNutrition tính trên edible amount. Nếu input là gross, phải có `edible_yield_ratio` hoặc hỏi user.Giải quyết dưa hấu, khoai tây, thịt/cá có xương/vỏ.
Missing conversionBottom sheet hỏi một câu cụ thể; lựa chọn `Chỉ lần này` hoặc `Nhớ cho sau`.Không silent convert; không fallback `g ↔ ml`.
SnapshotRecipe/pantry usage lưu `conversion_snapshot_json`; meal/food log lưu `nutrition_snapshot_json`.Tránh drift khi conversion/nutrition master đổi sau này.
TerminologyUI dùng “món ăn/công thức” nhưng runtime hiện có thể giữ entity `dish` trong Phase 1.Tránh rename runtime quá sớm.
