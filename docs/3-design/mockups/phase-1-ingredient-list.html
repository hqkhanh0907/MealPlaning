🚫 Delete rule: Ingredient used in ≥1 dish → hard block (no delete). Dialog: "Không thể xóa" + [Đóng] + [Xem N món đang dùng] (actionable CTA). Only unused ingredients show confirm dialog with [Xóa].
👆 Interactions: Tap card → navigate to edit page. ⋮ more icon top-right of each card (44×44 hitbox) → popover menu with [Sửa] + [Xóa] options. This is the PRIMARY and ONLY mechanism for edit/delete actions.
Easing — microcubic-bezier(0.25, 1, 0.5, 1) 200msFilter chip select, search focus, dialog open
Easing — snappycubic-bezier(0.16, 1, 0.3, 1) 150msFAB button press, filter chip tap, scroll-top button press
Easing — sheetcubic-bezier(0.32, 0.72, 0, 1) 300msBottom sheet / popover menu open. Exit: 225ms (75%)
Tabular numbersfont-variant-numeric: tabular-numsAll numeric values (kcal, macro g) for consistent column alignment
⚠️ Icon placeholders: Tab bar emojis (🏠📅🍳💪) and empty state emojis (🥗🔍) are mockup placeholders. Implementation uses IonIcon from Ionicons: home-outline, calendar-outline, restaurant-outline, fitness-outline. Empty states use themed SVG illustrations.
♿ Accessibility: Delete dialog: role="alertdialog" + aria-modal="true" + aria-labelledby + aria-describedby. ⋮ menu: dynamic aria-label="Tùy chọn cho [tên nguyên liệu]" + aria-haspopup="menu" + aria-expanded. Filter chips dùng button + aria-pressed để thể hiện trạng thái active. Search: role="search" + aria-label="Tìm nguyên liệu". List: role="list" with role="listitem". Delete CTA dùng label cụ thể kiểu "Xóa nguyên liệu Hạt chia".
